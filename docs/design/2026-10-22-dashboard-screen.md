## 一、图表色板

### 1.1 设计约束

| 要求 | 标准 | 依据 |
|---|---|---|
| 图形元素对背景 | ≥ 3:1 | WCAG 1.4.11 非文本对比 |
| 图表内文字 | ≥ 4.5:1 | WCAG 1.4.3 正文对比 |
| 相邻色可区分 | ΔE ≥ 10 | 避免色盲用户混淆 |

### 1.2 色板（三主题）

**light**（背景 `#ffffff` / 沉底 `#f5f6f7`）

| # | 色值 | 对背景 | 用途 |
|---|---|---|---|
| 1 | `#2f6bff` | 4.50 | 主色，最高频（单系列默认） |
| 2 | `#18a058` | 3.38 | 成功 / 正向 |
| 3 | `#bd7a18` | 3.52 | 警告 / 中性 |
| 4 | `#d03050` | 4.98 | 危险 / 负向 |
| 5 | `#2080f0` | 3.88 | 信息 |
| 6 | `#7c3aed` | 5.70 | 紫，色相补位 |
| 7 | `#0e9aa7` | 3.39 | 青绿 |
| 8 | `#868b93` | 3.43 | 兜底 / 其他 |

> **为什么琥珀是 `#bd7a18` 而不是 `--fbk-amber-500`（#f0a020）？**
> amber-500 在白底上只有 **2.15:1**，不满足图形元素的 3:1。

### 1.3 令牌命名

```css

--fbk-chart-axis-line                  轴线
```

## 二、`@fbk/dashboard` 设计

### 2.1 视觉基调

**嵌入后台页面**，所以必须与 ProTable / QueryForm 同一视觉语言：
白底卡片、`--fbk-shadow-sm` 阴影、`--fbk-radius-lg` 圆角、
`--fbk-spacing-lg` 内边距。不引入任何"科技感"装饰。

### 2.2 `StatCard` 规格

```
┌─────────────────────────────────────┐
│  总销售额                    [icon]  │  ← 标题 14px 次级色
│                                      │
│  1,284,500                           │  ← 数值 28px semibold 正文色
│  ↑ 12.5%  较上月                     │  ← 变化率 12px + 趋势色
│  ╭──────────────────╮                │
│  │  ~~~~ 迷你趋势    │                │  ← 可选，高 32px
│  ╰──────────────────╯                │
└─────────────────────────────────────┘
```

| 项 | 值 |
|---|---|
| 卡片内边距 | `--fbk-spacing-lg` (16px) |
| 圆角 | `--fbk-radius-lg` (10px) |
| 边框 | `1px solid var(--fbk-color-border-light)` |
| 标题字号 | `--fbk-font-size-sm` (12px)，次级色 |
| 数值字号 | 28px（组件令牌 `--fbk-stat-value-size`），semibold |
| 变化率字号 | `--fbk-font-size-sm` |
| 正向色 | `--fbk-color-success-text` |
| 负向色 | `--fbk-color-danger-text` |

**数值用等宽数字**（`font-variant-numeric: tabular-nums`），避免刷新时宽度跳动。

### 2.3 `StatGroup` 栅格

响应式：`<640px` 1 列 / `640-1024` 2 列 / `>1024` 4 列（可配置）。

### 2.4 图表容器

所有图表组件（TrendChart / BarChart / PieChart）共用一个外壳：

```
┌─────────────────────────────┐
│ 标题              [extra]   │  ← 标题区，高 48px
├─────────────────────────────┤
│                             │
│        图表区                │  ← 默认高 280px
│                             │
└─────────────────────────────┘
```

标题区与图表区之间**不加分隔线**（避免视觉噪音），靠间距区分。

### 2.5 `RankList` 规格

```
1  华东区        ████████████  48.2%
2  华南区        █████████     36.1%
3  华北区        ██████        24.7%
```

- 序号：等宽数字，前三名用 `--fbk-chart-1/2/3` 着色
- 进度条：高 6px，圆角 full
- 百分比：等宽数字，右对齐

## 三、`@fbk/screen` 设计（科技蓝）

### 3.1 设计基准

**1920 × 1080**，等比缩放居中。所有尺寸按这个基准写死像素，
靠 `transform: scale()` 适配。

### 3.2 色彩

| 用途 | 值 |
|---|---|
| 背景 | `#050910`（比 cyber 的 `#0c1420` 更深，大屏需要更强对比） |
| 面板底 | `rgba(12, 20, 32, 0.72)` 半透明 + 背景网格透出 |
| 面板边框 | `1px solid rgba(34, 211, 238, 0.28)` |
| 主强调 | `#22d3ee` |
| 标题文字 | `#e6f7fb` |
| 次级文字 | `#94b8c4` |
| 网格线 | `rgba(34, 211, 238, 0.06)` |

### 3.3 背景装饰

两层叠加：

```css
/* 第一层：径向光晕，中心偏上，模拟"仪表盘"聚焦感 */
radial-gradient(ellipse 80% 50% at 50% 0%, rgba(34,211,238,0.10), transparent 70%),
/* 第二层：网格 */
linear-gradient(rgba(34,211,238,0.06) 1px, transparent 1px) 0 0 / 40px 40px,
linear-gradient(90deg, rgba(34,211,238,0.06) 1px, transparent 1px) 0 0 / 40px 40px
```

### 3.4 `ScreenHeader`（高 80px）

```
        ┌──────────────────────────────────────┐
        │     ╱▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔▔╲            │
        │    ╱   运营数据监控中心    ╲          │  ← 标题 32px，字距 0.08em
        │    ╲____________________╱            │  ← 底部装饰线（发光）
        │  2026-10-22 21:00:00      [全屏]     │  ← 左右两侧
        └──────────────────────────────────────┘
```

- 标题：32px semibold，`letter-spacing: 0.08em`，带 `text-shadow` 发光
- 底部装饰线：渐变（透明 → 青色 → 透明），高 2px
- 时间与全屏按钮绝对定位在左右两端

### 3.5 `ScreenPanel`

```
╔═══════════════════════════════════╗   ← 四角装饰（L 形，2px 青色）
║  ▍ 区域销售分布          [更多]    ║   ← 标题前有 3px 竖条
║                                   ║
║        内容区                      ║
║                                   ║
╚═══════════════════════════════════╝
```

- 四角装饰用 `::before` / `::after` + 内部两个 `span`（或用 `clip-path` 边框）
- 标题竖条：3px × 16px，`--fbk-chart-1`
- 面板内边距：`--fbk-spacing-lg` (16px)

### 3.6 `ScreenNumber`（数字翻牌）

指标数字带滚动动画：

```
1,284,500
```

- 字号：40px（`--fbk-screen-number-size`），等宽数字
- 动画：数值变化时 `requestAnimationFrame` 从旧值过渡到新值（800ms ease-out）
- 尊重 `prefers-reduced-motion`

### 3.7 `ScreenScrollList`（轮播列表）

监控大屏高频组件：

- 每行高 44px，隔行背景 `rgba(34,211,238,0.04)`
- 自动向上滚动，鼠标悬停暂停
- 无缝循环（内容复制一份）

## 实现后的验证记录

### 单元测试（108 条新增）

jsdom 里 ECharts 无法真实绘制，所以单测覆盖的是**编排逻辑**：

| 包 | 测试数 | 覆盖内容 |
|---|---|---|
| chart-core | 45 | CSS 变量解析、主题桥、FbkChart 生命周期 |
| dashboard | 29 | 数值格式化、变化率语义、栅格、排行榜 |
| screen | 34 | 等比缩放数学、面板、数字动画、轮播列表 |

### 真实浏览器验证（`scripts/visual/verify-charts.py`）

单测覆盖不到的部分，用 Playwright 补：

- canvas **是否真的有像素**（不是空白）—— 通过采样 `getImageData` 判断
- 1920×1080 / 1440×900 / 2560×1440 / 1280×720 四种分辨率下
  构图比例是否保持 16:9、舞台是否超出容器
- 三套主题下 `--fbk-chart-1` 是否真的不同
- Canvas 是否报 `addColorStop` 错误

### 这一步抓到的 3 个真实缺陷（单测全部通过，但仍有问题）

1. **图表令牌被插进了 `.fbk-scope` 块而不是 `:root`**
   `document.documentElement` 读不到，`resolveChartTheme()` 全部回退到内置默认色，
   导致三套主题的图表配色**完全一样**。单测用 `setProperty` 伪造变量，
   所以测不出来 —— 只有真实浏览器能发现。

2. **`transform` 顺序错误**
   写成 `translate(-50%,-50%) scale(s)`，而 `transform-origin` 是 top left。
   translate 的百分比作用在未缩放坐标系，实测舞台顶部偏移 24.5px、底部溢出。
   正确顺序是 `scale(s) translate(-50%,-50%)`。

3. **仪表盘的 detail 与 title 位置重叠**
   `offsetCenter` 分别是 44% / 78%，与刻度标签挤在一起。
   调整为 38% / 72%，刻度 `distance` 从 14 收到 6。

### 教训

**「单测全绿」不等于「能用」。** 前两个缺陷都是纯 CSS/DOM 行为，
jsdom 不计算布局，永远测不出来。样式类改动必须过一遍真实浏览器。
