## 运行时语义

**无限滚动：空页即结束** —— 只认 hasMore === false 时，业务方按最常见的
{ list, total } 返回会让触底一页页往后请求、每页追加 0 行、底部一直转圈。
现在「这一页 0 行」也算到头（代价是最后一页刚好满行时多发一次请求）。

**useAdapter 复用全量校验** —— 三条入口对同一个适配器必须给同一个结论。
以前 useAdapter 只查 apiVersion：版本号正确但缺 DataGrid / RootProvider 的适配器，
assertAdapterCompatible 拒绝、useAdapter 放行。现在首检跑 版本 + 全量校验，
通过后记进 WeakSet，后续零成本。

**CrudPage 补三个查询区插槽**（actions / before-actions / after-actions）——
以前它们被白名单挡在外面，想放「导出」「高级筛选」按钮没有任何位置。

## 门禁不再假绿

· check:size 加反向遍历：基线里有、这次没测到的入口 → 报红（删导出是破坏性变更，

· check:api-snapshot：零 .d.ts 入口从「跳过」改成失败 —— 覆盖面缩到 0 时必须响。

· check-package-types：改成递归发现，与另外三处同步（写死三层目录会让新分组静默不查）。
